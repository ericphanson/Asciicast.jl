# Cast fixtures

These asciicast files were written by other tools, and are used in `test/runtests.jl` to check
that `parse_cast` reads files that Asciicast.jl did not generate. They are copied unchanged
from the repositories below (`.gitattributes` keeps their line endings unchanged on checkout).
Each file remains under its original licence; the full licence texts are in `LICENSES/`.
